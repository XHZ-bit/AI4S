# 个人账户与逐步学习

本页说明保留的个人设置及逐步辅导入口。PaperStride 1.0 的主要学习路径从统一图谱节点开始，使用真实前置关系和自评学习状态，见[当前交付说明](unified-release.md)。下面的固定案例与旧辅导入口均可按需使用，不是必修课程。

## 使用入口

- `/settings`：个人资料、头像、学习功能、辅导模型、注册登录和密码修改。
- `/learn`：逐步辅导；基础课程与 Python 练习。
- 阅读论文时，在辅助面板选择“问导师”，或在原文定位后选择“请导师拆解这段”。

本机模式允许继续使用原有本机空间；登录后使用 `data/users/<account-id>/` 下的独立空间。注册不会迁移或删除本机资料。退出登录可回到本机空间。受控多人部署仍要求登录。

`REGISTRATION_ENABLED=false` 可关闭自助注册。注册账号固定为普通用户，管理员继续使用已有 CLI 创建和管理。密码至少 12 个字符，服务端保存 scrypt 哈希；会话使用 HttpOnly Cookie，已登录写操作校验 CSRF。

## 个人模型

关闭自定义配置时使用平台预设 Qwen。启用时填写公开 HTTPS 的 OpenAI 兼容 Chat Completions 基础地址、模型名称和密钥，保存后可以主动测试。该配置用于个人辅导和辅助解读，不更换全平台的抽取、嵌入或科研规划模型。

API Key 使用 Fernet 加密，不返回给浏览器，也不写入日志。部署加密密钥为数据根目录 `.model-key`；备份必须保留它与各用户的 `preferences.json`，否则无法解密已有个人 API Key。多人备份工具已包含该文件。备份中包含解密材料，应按凭据文件保护。

自定义服务地址拒绝本机、内网、保留地址、非 HTTPS、非标准端口以及跳转；每次调用重新检查地址。当前不支持个人配置本地 Ollama、Anthropic 原生协议或 OAuth 模型订阅。问题与所选原文会在主动请求辅导时发送给提供商。每个空间每小时最多 40 次调用，全局同时最多 4 次，不自动重试扣费请求。

## 学习方式

三个预设为新手学习、论文精读、科研规划。基础补课、术语、小测、代码、可视化、辅助解读、路线、图谱均可独立开关。关闭辅导与题目后服务器也拒绝相应生成或提交；已保存记录保留。

五节人工编写课程覆盖概率与期望、向量矩阵、梯度、条件概率、模块化线性预测器。小测在服务端判分并给出反馈；模型生成小测是教学建议，不作为能力认证。开放问题可请求导师检查表述，也可要求换例子重讲。

Python 使用随应用提供的 Pyodide 文件，在无同源权限的 sandbox iframe 内，通过独立 Worker 运行，不在后端执行学生代码，运行环境无法读取应用的会话或浏览器存储。首次加载约 14MB；加载超时 45 秒，每次执行超时 5 秒，可随时停止。练习含填空、调试、代码分析、短函数与模块化实现，检查有限示例，结果按 `browser_self_reported` 保存。不能用于运行完整深度学习训练或证明论文复现成功。

## 验证

后端：`python -m pytest tests/test_personal_learning.py tests/test_multiuser_isolation.py`

前端：生产构建；浏览器检查注册、登录、退出、修改资料、头像、开关持久化、实际 Python 输出、错误反馈、超时、逐步辅导和手机双主题布局。基础课程离线可用；模型辅导需要可用的提供商配置。


## 学习闭环与按需生成

逐步辅导页的“学习档案、课题偏好与调用记录”提供知识点检查、独立学习课题设置及最近 30 次调用的耗时和 token 用量。学习课题是个人辅导范围的命名偏好，不修改科研课题的资料与执行计划。课题可裁剪基础解释、术语、小测和代码；个人全局关闭的功能不能在课题中重新开启。

知识档案根据每个基础知识点不同题目的最近一次作答整理，显示尚未检查、建议复习、继续检查或继续实践。重复回答同一道题不会增加检查覆盖数。档案随当前账号保存，导师可据此调整讲解；它不是能力认证。

首次提问仅生成讲解，点击“准备本节小测与代码实践”后才生成练习。练习可继续选择预测输出、填空、调试、模块组合或改变输入的小实验。每次明确请求会调用模型；已有辅导可直接从历史读取，不重复调用。生成题目与测试仍需结合原文检查。

历史辅导保存所选来源快照、页码及段落标识，并记录快照 SHA256。历史追问可恢复原文；旧版没有快照的记录无法追溯补建原文。

代码练习包含运行前预测与实验后解释；实验笔记保存于当前浏览器，代码检查记录保存于账号。实际执行仍使用隔离的浏览器 Python 环境。导师提供的参考实现和检查条件可能有误，可以查看并修改，不能据此认定完整论文已复现。

停止等待会保留之前的讲解和输入；已发出的提供商请求可能继续完成及计费，稍后可在历史和调用记录中查看结果。模型用量只展示提供商返回的 token，缺失时显示未提供，不推算金额。
