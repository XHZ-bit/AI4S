实施日期为 2026 年 11 月 16 日。依据 [平台建设计划](../platform-implementation-2026-11-16.md)实施，桌面浏览器优先。比赛讲解安排单独保存于 [PPT 方案](../competition-platform-plan-2026-11-16.md)。

## 已接入正常入口的功能

| 使用位置 | 实际行为 |
| --- | --- |
| 研究空间首屏 | 编辑并版本化保存当前问题，切换问题图谱和完整浏览。问题旁只给一个主要下一步，可查看原因、换起点。 |
| 初次深入学习 | 继承研究问题和使用方式，零基础默认重点理解；保存的个人讲解及深度优先，读取页面没有自动请求模型。 |
| 图谱节点与关系 | 单击独立侧栏，关系先显示双方含义、解释、出处及状态。修订折叠，先修路径快捷访问。同名跨来源概念显示待核对候选。 |
| 原文往返 | 保留节点与关系、图谱锚点、视口及键盘焦点。学习页减少重复标题，公式、代码和证据延用精确定位。 |
| 练习 | 按已确认对应ID与修订号准备专属练习，保存对应快照、预测、输入、输出和解释。对应变化时历史仍可读，新生成与运行要求重新核对。 |
| 笔记 | 问答选入笔记携带实际回答的问题、证据ID、版本、摘录和定位。保存后可以重开来源，变化提示和导出使用快照。 |
| 继续学习 | 首页展示同一账号及空间的暂停对象和未决问题。恢复期间保留未决内容，判断依据版本与当前导航版本分别保存。 |
| 资料比较 | 方法机制、研究设计与发现两种模板，逐格改选依据及记录人工核对。重新生成合并最新人工决定。 |
| 独立比较成果 | 继承问题，选择单元格、写个人解释及未决问题，预览、保存、重开、下载Markdown，包含原文版本和位置。 |

同设备续学信息按账号与空间隔离保存在浏览器。研究问题、笔记、比较成果和练习记录沿用服务端保存。词项匹配与已有自评、路径决定首版推荐，依据不足时显示现状，用户可以自行更换。

## 接口与兼容

- 项目问题使用已有项目更新接口及 expected_version。
- 练习读取和生成增加可选 mapping_id、mapping_revision，生成提示与缓存纳入对应快照。历史只读打开与新的确认分开处理。
- 记录保存增加 evidence_references，服务端按当前空间的证据标识捕获可靠快照，保存旧笔记时保留原引用。
- 比较预览、生成、修订增加可选 template，修订增加 evidence_ids 与 reviewed。证据必须属于本空间和本资料，人工核对记录操作者及时间。
- 比较新增 evidence 查询及 outcomes/preview、outcomes 保存和读取。成果复用版本历史表，保存时检查比较修订号。
- 旧资料、旧节点笔记和没有对应的练习沿用原有入口。界面新增字段采用可选项。
