# 代码练习工作台：编辑空间、运行结果与可调布局

## 改动目标

用户截图中的练习页把学习状态、生成设置、版本与输入全部纵向堆叠，题目和代码区没有共同高度，左侧大量留白，运行和保存需要向下寻找。本轮优先桌面浏览器，把主要空间交给代码和题目，减少整页滚动。

布局参考 [VS Code 的基本工作区](https://code.visualstudio.com/docs/editing/getting-started/userinterface) 和 [自定义布局](https://code.visualstudio.com/docs/configure/custom-layout)：辅助视图放在侧栏，编辑器居中，输出位于编辑器下方。PaperStride保留自己的节点、原文依据、教学练习和学习记录，不引入完整IDE或新的编辑器依赖。

## 交付内容

- 顶部只保留返回、节点标题、练习生成入口、图谱定位、当前目标与版本。去除工作台原有的第二行节点导航，避免重复占用高度。
- 左侧“题目 / 输入 / 学习记录 / 设置”按任务切换。题目包含预期观察、按需提示、检查条件及原文依据；输入集中放置stdin、JSON与绘图示例；学习状态、小结及历史运行移入明确的学习记录入口。
- 右侧上方是代码编辑器，增加同步行号、横向滚动与草稿状态。保留Tab缩进、Shift+Tab离开编辑器。切标签、调整分栏和显示结果均不重挂编辑器。
- 运行、提交检查、AI分析、保存与恢复操作常驻在编辑器下方；执行时出现停止操作。输出和AI分析在下方标签切换，各区域独立滚动。
- 左右分隔线和结果区分隔线均可拖动，也可用方向键、Home/End、Enter或双击操作。当前浏览器按账号、课题、节点保存明确调整的尺寸，缩小窗口会约束尺寸而不抹掉原偏好。
- 顶部“生成专属练习 / 调整练习”打开设置；设置内“按目标生成 / 调整练习”才实际提交生成请求。打开页面、切标签、调布局不触发生成。

保存和运行沿用现有接口、本机Python运行器、练习历史、输入约定与版本。非法JSON保留原稿，并直接切到输入页提示修正；来源对应过期时在工作区上方显示原因，继续禁止运行和提交。AI分析仅携带匹配当前代码与输入的运行输出。

本轮同时修复了切换练习版本后的运行解释绑定：接受新版本时清空旧运行ID、预测及解释；旧版本延迟返回的保存响应不能把解释绑定到新版本。保存解释也会检查当前节点与练习范围。
