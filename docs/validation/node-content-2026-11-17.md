# 知识节点内容与阅读上下文补充

用户反馈进入具体节点后内容太少。检查发现，未准备深入讲解时，页面主要使用节点摘要和原文摘录；部分节点只有一句英文定义，关系说明与可选基础也较深地折叠。

## 本轮调整

- 节点侧栏首屏加入简明教学解释、用途和关键点，例子及常见疑问按需展开。保留节点原描述，与通用教学分开。
- 首屏显示当前节点直接原文片段，预览限440字符，打开原文仍传递完整证据。依据按节点证据ID、同一来源及有效标记筛选；关联和历史来源单独展示。
- 图谱上下文明确显示起点、关系、终点及已有解释，前三条常显，其余展开。真实先修和可选教学补充都带摘要，后者不自动成为必修关系。
- 深入学习页在基础状态直接展示通用教学，包含直观理解、用途、过程、手算例、要点、误区与思考问题。原文描述和原文依据继续保留。
- 已有个性化讲解或人工修订优先占主阅读区，通用内容收进“回顾基础讲解”，不覆盖保存的正文、隐藏选择、深度或问题。

## 内容范围

首批7个主题为Self-attention、缩放点积注意力、softmax、向量点积、概率、研究设计、样本与总体。教学内容由项目编写，以 `authored_teaching` 与固定版本返回，不写成论文原作者陈述，不自动生成图谱关系或保存到讲解记录。

Self-attention讲解区分信息来源、Q/K/V角色、掩码、缩放点积、多头和交叉注意力。两位置教学例给定权重0.75、0.25与值2、6，结果为3；这些是教学输入，不是训练或论文实验结果。无源码的研究设计节点也提供因素、测量、条件与结论范围的学习内容。

按当前节点自身标签优先匹配，其次使用自身描述或公式。普通心理学“注意力”、未知主题、显式Cross-attention/Multi-head标题不会因为对比提到Self-attention而套用自注意力教材。来源、依据或节点不可用时不挂当前教学指南。

未匹配主题继续展示实际摘要、有效原文及图谱关系，可以使用已有按需深入讲解入口。本轮没有承诺所有领域都已编成完整课程。

## 实现

`backend/app/knowledge/node_guides.py` 提供无网络的 `get_guide(node)`，`learning.detail()` 在有效上下文中返回可选 `study_guide`。接口与旧空间兼容，读取不会请求模型或外站，不修改原始节点说明、引用或已保存讲解。

前端复用 `NodeStudyGuide` 的侧栏与正文两种呈现，并在学习目录加入基础讲解或基础回顾。知识来源、关系方向和范围说明沿用现有数据。
