# 深入学习工作台：阅读分区、常驻工具与公式排版

## 本轮改动

这轮回应用户六张实际截图：公式环境被原样显示、长证据使页面过长、个性化讲解入口藏在设置里，以及学习状态、小结、提问和笔记全部位于正文底部。

之前将生成按钮连同目标设置一起折叠，增加了操作成本。本轮把主操作与设置分开：顶部始终显示“生成个性化讲解”，保存或失败后对应“更新/重试个性化讲解”；调整目标和深度仍是次要展开项。生成、原文依据与人工内容保护规则继续保留。

桌面采用阅读器与常驻工具并排的结构：

- 主阅读区有“讲解 / 原文依据 / 练习与实现”三个标签。各自独立滚动，标签切换后保留已打开内容与未保存讲解修订。讲解的章节选择可直接跳到推导或边界。
- 右栏始终显示学习状态选择和“查看学习小结”。其下用“提问 / 笔记 / 学习记录”切换，打开小结会直接显示已有记录，不自动生成AI建议。
- 同一节点切换提问与笔记时保留输入。回答可以加入笔记草稿；换节点清空当前问答，笔记沿用原有按账号、课题及节点保存的本机草稿。
- 图谱、论文原文与学习页继续沿用原来的定位、返回和来源版本。阅读标签及滚动位置按账号、课题、节点在当前浏览器会话保存，原文往返不需要重新翻到旧位置。

主面板和工具面板使用视口剩余高度，不把所有模块连续堆成一条很长的页面。1366桌面右栏默认360px，较宽桌面为400px；手机适配不在本轮范围。

## 原文依据的密度与准确性

直接依据根据当前节点的证据ID判定。同篇检索到的其他片段显示为“同篇相关上下文”，其他资料显示为“比较与关联来源”，不会仅因为属于同一篇论文就全部称作当前节点的直接依据。

同段内容去重时优先保留直接引用身份。每组初始最多展示6条，条目折叠展开，只有首条默认打开，可以继续每次显示6条。打开原文再返回时恢复分组、数量、展开状态和阅读位置；完整摘录与定位信息保留，源码片段仍按字面显示。

## 公式展示

本轮统一共享公式分段与排版入口，覆盖无外层定界符的LaTeX环境、多行aligned、嵌套矩阵、已有定界符及错误排版回退。编辑输入、代码块与源码证据保持原始文本；未知命令、破损转义或损坏识别文本不通过猜字母伪造公式，可展开原式或返回原文核对。

完整展示入口审计、测试和限制见 `math-rendering-2026-11-17.md`，工程验收针对排版和回退，不等于独立验证所有公式的科学正确性。

## 布局参考

采用以下官方公开交互模式，结合PaperStride自己的证据、讲解和学习记录：

- [Zotero PDF Reader](https://www.zotero.org/support/pdf_reader)：正文与笔记侧栏并排；笔记保留返回原文位置的链接。
- [Obsidian Sidebar](https://obsidian.md/help/sidebar)：固定侧栏内用标签切换工具，主阅读位置保持。
- [Notion Comments pane](https://www.notion.com/help/comments-mentions-and-reminders#comments-pane)：显式入口打开记录面板，减少寻找与跳转。

这里借鉴的是工具位置与任务连续性，不把这些产品描述为同题功能或效果已实测。
