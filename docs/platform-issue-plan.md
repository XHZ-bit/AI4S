## 本轮目标与范围

新手从一份论文或源码提出问题，在图谱中找到相关概念和原文依据，沿先修路径进入节点学习，完成代码题并理解反馈。再次打开平台时可以接着学；如果遇到困难，可以看到有记录支持的补强建议。熟悉课题的用户仍可自由探索、比较方法、修订自己的知识。

建议首条完整路径采用“策略均值有界时，采样值也有界吗？”。串起 4–6 个节点、两道可判定练习、一次查原文和一次错题补学；另选一份新资料验证同一套机制。题量是首周工作量建议。若团队有更熟悉的研究问题，可以替换题材。

**范围标记**：“首周”指建议先做通的最小范围。“后续”表示需求保留，列出的能力可单独排期。每项中的方框供审核后开发验收使用。

## A. 现有问题与公共体验

### PS-01｜建立平台遗留问题清单和回归基线

**首周 · 平台维护 · 可立即开始**

从新用户、回访用户两种身份，实际走一遍首页、导入、图谱、原文、学习、练习、比较、设置。按用户任务梳理当前与历史路由、数据读写入口和配置，复现问题后按影响分为阻断、功能缺陷、体验瑕疵。将每个独立缺陷登记为可关闭的子 issue。

- [ ] 每条缺陷有入口、复现步骤、实际表现、期望结果及修复归属；无法复现的疑点有单独状态。
- [ ] 优先核验两个代码中可见的现象：普通入口重开只恢复部分位置；重新进入练习后，已有运行历史的入口随本页输出状态隐藏。分别交给 PS-10、PS-08。
- [ ] 建立新建空间和旧库副本两组基线，记录代表性原文定位、人工修订、笔记、草稿和旧链接，供 PS-02 和 PS-15 对照。

### PS-02｜修复旧入口、重复实现与版本不一致

**首周先修阻断项，后续逐条清完 · 平台维护 · 依赖 PS-01**

核对导航与深链接、旧 API 映射、配置开关、数据迁移和同功能多版本实现。活跃知识沿用统一存储。对仍由用户历史数据或调用方使用的路径，采用兼容读取或重定向；对无引用的运行时代码，确认引用关系后再归并或移除。

- [ ] 从旧节点链接可以到达正确空间、节点和来源；旧数据升级后保留原文、笔记、人工修订和冻结快照，重复迁移结果一致。
- [ ] 同一对象从新旧入口查看时内容一致。移除或合并的入口有对应复验，源文件和用户资料可以区分。
- [ ] 阻断问题全部修复才关闭首周里程碑；其余已确认缺陷上有独立编号并持续跟踪。遗留清单逐条复验完成后再关闭本项。

### PS-03｜精简首页与空间导航，统一操作反馈

**首周 · 前端体验 · 可与 PS-01 并行，最终接入 PS-10**

沿用现有字体、配色和组件样式。首次使用突出导入资料或进入学习示例；回访突出继续当前任务。空间内按用户现在要做的事组织入口。无内容的可选模块收起，有明确下一步的空状态提供就地操作。统一加载、保存、失败、取消和重试反馈。

- [ ] 新账号首屏能直接开始一个真实任务；已有学习记录时能一键继续。当前主要操作清晰，无内容的可选栏目不占主阅读区。
- [ ] 点击保存、运行、重试立即有可见反馈，等待时避免重复提交；失败保留输入并在操作位置说明原因。
- [ ] 桌面与窄屏均可完成主操作，浅深主题下焦点清晰，键盘可用。进度与错误同时有文字说明。

## B. 知识图谱与节点学习

### PS-04｜打通“导入资料 → 有依据的关系 → 原文”探索流程

**首周 · 图谱与资料 · 可立即开始**

复用资料解析、已有图谱和来源定位。在分析过程中优先开放已就绪的原文与结构块。图谱默认聚焦当前问题或选中节点，支持搜索、预览、展开邻接关系。分别显示实现、使用、支持、先修等有实际依据的关系；保留原文明示、系统推断和用户补充的区别。

- [ ] 从导入的新资料进入实际生成的节点，无需依赖示例 ID；上传过程中能看到真实阶段、已有原文、失败或中断后的可用操作。
- [ ] 从一条关系能读懂其方向与含义，并打开与该判断匹配的原文或代码行。无法定位或缺少依据时明确提示，允许核对、修订。
- [ ] 跨资料案例能沿关系从方法到实现；撤回关系或移除来源后，当前探索和路径反映变化，历史笔记保留。窄屏或键盘用户可用等价的节点列表完成导航。

### PS-05｜从科研目标生成个人学习地图

**首周 · 图谱与学习 · 依赖 PS-04 的关系约定，复用现有个人进度**

让用户选择“我想理解哪个方法或节点”，系统沿明确的先修边生成路线。在同一组节点上提供“全局探索”和“我的路径”，支持支线、自选跳过、返回目标及手动复习。每个推荐给出可读理由。

- [ ] 同一目标、不同先修状态的两位用户可以看到不同的建议下一步。普通关联边不产生强制关卡。
- [ ] 路线上能区分当前、可学、已完成和待复习；用户能点开任一可访问节点，查看目标和学习内容。
- [ ] 遇到环、断边、无先修或缺证据的节点，仍可直接学习目标，并能看懂路径为什么停在这里。

### PS-06｜把节点详情做成能完成的学习单元

**首周 · 学习内容与前端 · 依赖 PS-04；可与 PS-05 并行**

节点首屏先回答“学完能解决什么问题”。按类型呈现内容：概念看直观解释和例子，公式看符号和条件，源码看关键行与实现，实验看设置和结论边界。从同一节点可以查原文、补前置、做适合的题，并回到原学习位置。

- [ ] 首条路径上每个节点都有学习目标、可读内容和一种检验理解的动作；非代码知识点可以用判断题或解释题。
- [ ] 无题目、无公式或无实验的节点不渲染对应空栏目。只有基础资料时仍可阅读，生成失败后可继续使用已保存的内容。
- [ ] 用户能识别原始来源、模型解释和自己的修订；重新生成或刷新后保留已保存的人工修订。

## C. 在线代码练习

### PS-07｜定义题目、测试用例与提交判定

**首周 · 练习逻辑 · 可立即开始**

复用浏览器 Python 和已有练习版本。每题记录关联节点、目标、函数签名、起始代码、输入输出、约束、提示和测试用例。区分自由运行、查看示例以及对固定用例提交。首周用当前运行时实际支持的 Python 标准库设计题目。

- [ ] 两道不同难度的题各有正确实现和含典型错误的实现，判定能稳定区分通过、答案不符、运行异常、超时。
- [ ] 失败用例能给出有教学意义的输入、预期与实际结果；公开说明采用浏览器本地学习判定。
- [ ] 记录题目版本、提交的代码和结果；重复请求不产生两份提交。旧练习仍能打开和运行，旧运行记录沿用原含义。

### PS-08｜实现题面与编辑器并排的做题工作台

**首周 · 前端体验 · 依赖 PS-07 的题目与结果格式**

桌面左侧为题面、样例和按需展开的提示，右侧为代码编辑、运行、提交和结果。手机使用题面、代码、结果切换。传统教学练习中的可编辑参数与图表继续可用。历史提交和运行记录独立于本次输出展示。

- [ ] 用户能编辑、运行自选输入、提交、定位第一个失败用例、修改并重交，页内获得完整反馈。
- [ ] 运行中可停止，错误后代码保留。切看原文、切回题面、刷新后草稿可恢复；已存历史在刚重开且尚未运行时也可查看。
- [ ] 在窄屏和键盘操作下，题面、代码、结果均可到达；查提示时不丢光标和编辑位置。

## D. 存档、续学与诊断

### PS-09｜统一学习记录，保留用户自评与实际表现

**首周 · 学习数据 · 可先定数据格式，与 PS-07 并行**

复用节点进度、练习草稿和运行记录。补足节点访问、看提示、提交及复习记录，按用户、空间、节点、题目版本关联。界面分别呈现“看过”“通过练习”和“自己认为理解”。

- [ ] 同一题可回看历次提交、反馈和最终结论；用户手动标记“需复习”后，下一次通过练习仍保留其自评选择。
- [ ] 刷新、重复写入或并发保存不会重复计数或静默覆盖新草稿。老记录缺少新字段时按已知信息展示。
- [ ] 两个账号、两个空间的草稿与进度不会串读。没有学习记录时从真实空状态开始。

### PS-10｜恢复上次任务与跨页面上下文

**首周 · 前端与存档 · 依赖 PS-09 的作用域，与 PS-03 对接**

增加显式的“继续上次任务”。复用工作台已保存的来源、节点、视图、页码、原文块、源码行和比较对象，并补齐主路径需要的图谱视野、题目与编辑位置。主动打开的深链接优先。

- [ ] 图谱 → 原文 → 返回后，仍是原节点和视野；练习 → 查公式 → 返回后，代码、草稿、光标和滚动位置可继续使用。
- [ ] 关闭浏览器再打开可回到上次学习节点、原文位置或未完成题。对旧记录只恢复其中确实存在的信息。
- [ ] 上次对象已移除时，给出原因并返回可用空间。切换账号后，前一个账号的续学信息不可见。

### PS-11｜让个人 API Key 或平台预设服务覆盖全部模型入口

**首周 · 模型服务 · 可立即开始**

沿用已有个人模型设置、加密存储与连接测试，接通知识抽取、节点提问、深入讲解、方法比较、练习生成和学习诊断。支持的预设提供商只需填 Key，其他兼容服务可以展开地址和模型设置。保留现有离线开关及各功能调用预算。

- [ ] 对各模型入口逐项验证：未填个人 Key 且配置了平台服务时走平台；启用有效个人 Key 时走个人配置；个人 Key 无效或超额时，提示并由用户选择是否切换，避免意外扣费。
- [ ] 设置页明确当前来源、连接状态和数据发送范围。服务端持有平台密钥；前端、日志、模型错误文本与诊断记录均不回显密钥。提供商地址变更后重新校验凭据。
- [ ] 离线或双方均不可用时，已存原文、图谱、练习、进度均可用，页面读取不触发模型请求；平台预设服务有明确的请求额度及耗尽反馈。

### PS-12｜建立经验库与可解释的补强推荐

**首周先做规则版 · 学习逻辑 · 依赖 PS-05、PS-07、PS-09**

经验条目包含错误现象、可能对应的概念、用来区分原因的问题、可学习的节点和练习。先覆盖首条路径的两个典型误解；综合失败用例与实际作答给建议。规则明确的推荐可离线使用。

- [ ] 能给出类似“你两次把均值当作采样结果 → 再试一题区分原因 → 回到对应知识点”的具体建议，并能查看所依据的提交。
- [ ] 一次超时、语法错误或没有作答，不会直接变成知识薄弱判定；证据不足时允许用户自选复习或先做辨别题。
- [ ] 补练后推荐能更新，可以忽略或稍后复习。访问或跳过推荐不会自动更改掌握状态。

### PS-13｜生成节点学习小结与阶段诊断

**首周争取节点小结；阶段报告排后续 · 模型与学习 · 依赖 PS-09、PS-11、PS-12**

节点完成后可查看已学内容、尝试、仍需练习的部分和下一步。用户主动请求时，模型基于当前范围内的真实记录与经验条目解释建议；后续支持按目标或时间段生成报告。

- [ ] 核心判断可点回对应节点、提交或提示记录；无证据时明确写出缺什么，不编造学习经历。
- [ ] 缺 Key、离线或超时时能查看基于记录的简要小结；重复打开同一份已生成小结不重复扣费。
- [ ] 第一份阶段报告只汇总用户选定范围；资料不足时展示已观察到的事实，不给虚假掌握分或跨空间引用。

## E. 内容样例、体验验证与后续深化

### PS-14｜制作一条完整的新手科研路径，并用陌生资料验证通用性

**首周 · 内容与产品 · 内容可先行；联调依赖 PS-04 至 PS-08**

为建议案例准备固定来源、4–6 个节点、两道题和典型误解。例如，区分均值与标准差，读源码定位分布的构造，再写出固定噪声下的采样计算。更换一个输入，观察结论。明确标注教学算例的适用范围。另取一份未用于该案例的新资料验证能导入、定位和学习。

- [ ] 不熟悉代码库的用户看得懂起点、学习目标和下一步，最终能回答原问题，并给出对应源码行或资料出处。
- [ ] 节点、题目和反馈能由通用数据驱动；换资料后入口正常，有依据的边可用，缺资料的部分如实显示。
- [ ] 记录一次新案例中关系错误或学习卡住的位置，并能从界面修订或调整；样例成功和新资料结果分别记录。

### PS-15｜完成平台端到端验收与实际试用

**首周 · 质量与全组 · 依赖本期入选项；测试脚本可从第 1 天编写**

使用旧库副本、新建库、支持的个人模型配置、平台预设和离线模式验证。从真实入口覆盖查证、做题、跨页、续学。找 2–3 位未参与开发的同学观察第一次使用；记录第一次明显停顿、求助及失败任务。

- [ ] 新用户完成“找到目标 → 查原文 → 运行与提交 → 查看结果 → 退出重开”；旧用户保留原文定位、修订、草稿及已有进度。
- [ ] 桌面与窄屏至少各走查一次。长任务反馈、失败恢复、无结果和断网均有可执行的下一步。记录用户完成数与实际耗时。
- [ ] 若出现数据丢失、跨账号泄漏、私下切换计费凭据或主流程无法完成，阻断本期验收，修复后重新走相同入口。

### PS-16｜深化跨论文图谱、比较与来源变更追踪

**后续 · 图谱与科研工作流 · 依赖 PS-04、PS-06**

复用已有方法比较、共同前置、来源版本和修订记录。围绕“同名概念在两篇论文中是否含义相同”“实验条件是否可比”“哪条学习结论需要复查”深化跨资料体验。

- [ ] 比较两个方法时能并排看到共同概念、不同实现和各自出处；指标定义或条件不齐时明确标出缺口。
- [ ] 资料更新后从受影响节点能找到相关比较或讲解，提示用户复核，并保留旧来源版本与历史修订。

| 第 6 天 | PS-15 实际试用，两种数据环境及离线/模型流程走查 | 记录最影响使用的卡点、错误、数据或版本兼容问题 |
| 第 7 天 | 修复并复验，汇总剩余子 issue | 首周通过项、未通过项和遗留缺陷都有真实复验状态 |

**时间不足时的取舍**：优先保住“一条带依据的学习路径、两道可提交的题、个人续学、模型配置正确、旧资料可用”。学习诊断先给真实记录与规则建议。多主题题库、额外运行时和复杂关卡视觉后排。若只有一人开发，第 1 周以这条路径的最小版本为目标，其余 issue 继续滚动处理。
