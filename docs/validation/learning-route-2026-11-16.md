# 可保存与接续的个人学习路线

本轮建设桌面网页端，把临时的先修路径查询接成可以保存、调整、复核和继续的学习任务。手机专项、竞品实际操作和真人学习成效测试不在本轮范围。

## 入口与使用路径

研究空间顶部新增“学习路线”。从已选中的图谱节点或深入学习页进入时，默认带入该节点作为候选目标，不自动生成或改写路线。

1. 选择或搜索目标，点击“预览学习路线”。沿当前有效的先修关系查看分支、出处和边界。
2. 确认后保存。每个空间保留一条当前路线，目标改变及每次人工修订均有历史。
3. 可逐步完成、本次跳过、重新进行和上下调整顺序。首屏读取保存结果，直接进入下一步。
4. 在深入学习页点击“完成这一步并继续”，保存当前任务步骤，并按服务端返回的下一步打开知识。理解程度继续由用户单独自评。
5. 从路线进入图谱，查看实际知识和真实连线。可以切换内容列表、选择节点、查原文，再返回路线或自由探索。
6. 来源、节点、证据或先修关系变化后，对照保存时和当前内容，主动确认当前依据；出现新先修遗漏时须重新规划。

路线顺序只安排本次学习，不建立新的语义关系，也不把普通关联或教学补充当作必须完成的先修。用户可以随时打开目标。

## 保存与复核

每次写入保存操作者、修订号、问题、目标、步骤状态、节点内容、来源版本、证据内容及位置、先修关系快照。使用事务和预期修订号防止并发覆盖。预览指纹包含当前上下文，同ID证据内容静默变化也会使旧预览失效。

完成步骤不改写 `kw_progress`。建议下一步依保存顺序和明确任务状态选择，不据运行成功或点击完成认定掌握。跳过是本次路线安排，后续可以撤销。

重新规划同一目标会保留仍有效的完成和跳过决定以及已有相对顺序，把新增先修插到相应依赖之前。问题改变只显示提醒，旧问题和旧决定仍可查阅。

失效步骤与其下游不进入直接继续建议。逐项复核不会自动补入新发现的先修节点，接口返回 `needs_replan` 和 `blocked_by`，页面明确要求检查或重新规划。被移除或依据失效的节点无法直接确认为有效。

图谱仅投影当前有效步骤与真实连线。路线布局单独保存，路线内的缩放、选择和阅读往返应保留进入前的自由探索画布。旧空间无路线时沿用现有阅读、图谱和指导。

## 范围与边界

- 预览最多40步、6层，并受原图谱5000节点与20000边的读取范围限制。截断、循环和无先修均有文字提示。
- 教学补充仍从既有学习入口就地阅读，本版不自动加入路线作为先修关卡。
- 缺少直接出处的可用知识可以安排学习，但明确提示未核实；覆盖数量与路线完成率均不等于科学正确性或学习收益。
- 页面读取、预览、调整及复核均不调用模型。生成讲解、资料分析沿用各自明确触发入口。
- 本版每个账号所属研究空间保存一条当前路线，修订历史读取最近50次。新增结构兼容无路线的旧空间。

## 接口

根路径为 `/api/projects/{pid}/knowledge/learning-route`，沿用项目权限与账号隔离。

| 操作 | 请求 |
| --- | --- |
| 读取 | GET，返回 `route` 或 `null` |
| 预览 | POST `/preview`，传入 `target_node_id` |
| 保存或重新规划 | POST，传入目标、`expected_revision` 和 `preview_fingerprint` |
| 状态或顺序 | PATCH，传入预期修订及步骤状态或完整顺序 |
| 逐项复核 | POST `/recheck`，传入步骤、预期修订及看到的 `expected_context` |
| 历史 | GET `/history` |

## 工程验证

新增后端路线测试14项，与学习、有效性、教学检查和概念核对相关回归共69项通过，日志 `.tmp/learning-routes-back.log`。覆盖分支、循环、无路径、教学补充分离、来源移除、同ID证据变化、先修新增、人工决定保留、跨空间和账号、并发修订及理解自评独立。

前端工作台、首页、路线、图谱和指导五文件46项通过，日志 `.tmp/route-front-regression.log`。就地完成、路线及指导最终三文件15项通过，日志 `.tmp/route-guidance-final.log`。

实际浏览器发现并修正了跨来源范围返回时的画布重置。修正后既有工作台22项通过，记录 `.tmp/learning-route-workspace-final.log`；同轮新增往返测试旧选择器曾触发15秒超时，改用精确选择后最终单项通过，日志 `.tmp/learning-route-canvas-fast.log`。图谱5项与该集成1项的合并检查也通过，日志 `.tmp/learning-route-canvas-return.log`。这些检查有重叠，不能直接相加，JSDOM耗时不是产品性能指标。

Ruff与相关差异检查通过。最终生产构建通过，记录 `.tmp/learning-route-build-final.log`。已有主包超过500kB的构建提示保留，不据本轮功能测试声称加载性能达标。

## 隔离资料与复验口径

`evaluation/research_atlas/prepare_route_fixture.py` 通过正常上传、原文解析、固定HTTP模型响应校验、知识抽取和建图建立自编注意力教学材料。两条先修分支为点积与Softmax到目标，另有正常教学目录产生的 `SUPPLEMENTS`，验收确认后者不进入强制路线。未直接预置语义节点或边。

最终资料目录为 `.ui_validation/learning-route-20261116-final`，fixture明确标记 `source_kind=authored_teaching_material`、`model_stub=true`、`real_provider_calls=0`。这些资料用于工程验收，真实供应商抽取质量、一般新论文适用性、节省时间和学习成效尚不能由此推出。

主流程由 `evaluation/research_atlas/run_route_browser.cjs` 在实际本机Chrome中执行，覆盖预览不落库、分支与教学语义、保存与刷新、任务状态、自评独立、图谱与键盘、首屏继续、原文往返、版本复核、来源移除及1366×768、1440×900、1920×1080浅深主题。跨视图画布恢复单独由 `run_route_canvas_browser.cjs` 检查。
