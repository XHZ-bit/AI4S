# PaperStride 平台基础与科研学习流程改进

本轮依据用户确认的方向实施：补齐完整流程、夯实技术和知识图谱语义、提供有用的学习内容，并保持主界面简洁。没有增加主导航栏目或全屏核查清单。

## 已实现

- 导入时区分原文保存与后台调度。队列满或执行器不可用仍返回已经保存的资料和可继续任务；未知程序异常继续报错。批量部分失败后刷新已有结果。资料处理摘要按需展开，继续分析复用完成缓存并保留人工修改。
- 科研图谱将主题匹配的教学目录与有来源的先修关系分开。教学补充使用 `SUPPLEMENTS`，不再借用论文引文；旧记录在读取时兼容投影。普通关联不生成先修路径，同名跨来源节点保持独立。
- 推荐、问答和实现上下文过滤已撤回、有争议及依据失效的事实；跨来源关系的任一引用变化时不再仅凭剩余引用继续使用。关系类型在服务端校验；补充教学内容不再把整篇论文当作自身定义来源。
- 核查绑定内容指纹和版本。公式、描述或再分析内容变化后，旧核查不能继续标为当前已核对；缺失块及无法匹配的引文不能核验。当前登录身份确定核查人，修订历史可按需查看。
- 节点的“我的理解”和“未解决问题”复用现有版本化笔记存储。支持草稿恢复、冲突保留、将问答选入笔记；首次进入记录页才加载笔记。深入学习页的笔记入口默认折叠。
- 学习成果可选择笔记、原文、已保存讲解、练习摘要及比较单元格，预览后下载 Markdown；默认空选，不调用模型。导出保留来源、定位、内容性质和版本。
- 已保存比较能够说明来源、相关知识或依据变化，并保留历史文本和人工修订。详细变化原因按需展开。

## 边界

工程回归和合成浏览器验收不能证明自动解释的科学正确性或普遍学习收益。本轮未开展队外真人试用、学科专家评审或新论文真实模型生成评估。部分解析的强制重做仍需要独立的解析版本兼容方案，当前“继续知识分析”复用既有解析。图谱手工布局仍保存在当前浏览器；服务端笔记与进度沿用账号隔离。
