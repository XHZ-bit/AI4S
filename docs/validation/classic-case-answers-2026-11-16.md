# 经典论文案例导入与固定答案

本清单供开发验收和用户录制时核对。导入使用平台正常的资料上传或链接入口，生成内容逐项核对。下列教学代码为项目自编，公开论文通过链接获取。

## Attention 主任务

研究问题填写“翻译一个词时，模型怎样决定参考句中的哪些词”。创建空间时选择零基础探索。通过资料入口导入 [Attention Is All You Need v7](https://arxiv.org/pdf/1706.03762v7)，记录界面返回的资料版本。资料保存后可先读原文，分析完成后从当前问题进入公式节点。

固定原文位置为 PDF 第 4 页第 3.2.1 节公式（1）。公式先计算 QK 的转置乘积，再除以 sqrt(d_k)，随后在一组分数上做 softmax 并作用于 V。

上传 [教学实现](../../evaluation/research_atlas/fixtures/attention_teaching.py)，在公式节点手工建立或生成对应，核对后选择教学类型。函数第 8–11 行，实际缩放在第 11 行。另上传 [错误候选](../../evaluation/research_atlas/fixtures/attention_counterexample.py)，第 7–8 行的同名函数计算乘法，应予驳回。重新生成后检查原决定保留。

练习先预测，随后使用教学代码和 JSON 输入运行。

| 输入 | 正确输出 | 检验的判断 |
| --- | --- | --- |
| dot=8，d_k=4 | 4.0 | 单个点积分数除以平方根 |
| dot=8，d_k=16 | 2.0 | 固定点积时增大缩放分母 |
| dot=-8，d_k=4 | -4.0 | 缩放分数可为负数 |
| d_k=0 | ValueError | 本教学函数的输入检查 |

4.0 是 softmax 前的单个分数。完整注意力权重需要一组分数，本算例只检验缩放项。将这个判断和“softmax 怎样把分数转成权重”保存为理解与未决问题，返回首页后继续上次任务。

## 论文比较

通过同一入口导入 [Bahdanau 等人论文 v7](https://arxiv.org/pdf/1409.0473v7)，选择方法机制模板。目标是对照打分方法及各自背景，分别查看出处。Bahdanau PDF 第 3 页第 3.1 节描述对齐打分，第 12 页附录 A.1.2 给出具体前馈打分形式。

固定答案为 Bahdanau 使用学习得到的前馈对齐模型，Transformer 的缩放点积机制使用点积及维度缩放。比较时保留编码器、解码器和任务背景，不用两篇报告的指标直接推断同条件优劣。逐格保存本人判断，再选格建立独立比较成果、预览、保存、重开与导出。

## 无源码的实证学习

采用 Roediger 与 Karpicke（2006）的 Test-Enhanced Learning。通过 [出版社原文](https://journals.sagepub.com/doi/full/10.1111/j.1467-9280.2006.01693.x)获取可访问的 PDF，或先使用 [PubMed 摘要](https://pubmed.ncbi.nlm.nih.gov/16507066/)核对摘要层面的条件和结论。摘要无法支撑全文页码或额外的实验细节。

研究问题为“练习回忆和反复阅读的效果怎样随测试间隔变化”。使用研究设计与发现模板，比较维度覆盖研究对象、实验材料、研究设计、测量、主要发现和适用范围。固定答案包含散文学习、无反馈的自由回忆、5 分钟及延迟测试。5 分钟时反复阅读表现更好，延迟测试时先前回忆测验更好。界面显示这项研究的结论与适用条件。

## 关系答案与回归记录

| 起点到终点 | 预期 | 需要的依据 |
| --- | --- | --- |
| 缩放公式到教学除法函数 | 可确认的教学对应 | 论文公式与实际代码行，双方版本 |
| 缩放公式到同名乘法函数 | 应驳回 | 运算不同，函数名称不足以证明对应 |
| 缩放分数到完整注意力权重 | 需要后续 softmax 步骤 | 原文公式，单个4.0不能充当权重 |
| 两篇论文到注意力打分比较 | 两侧分别引用后可核对 | 每篇具体位置及所比较的模型条件 |
| 学习策略到记忆结果 | 条件性结论 | 学习方式、测试间隔及结果对应 |
| 相同概念名到自动合并 | 保留候选 | 分别检查定义和适用条件 |

工程记录每次写原文定位命中数、正确关系、错误关系、证据不足、遗漏和方向错误。缺源码时保留论文学习与手工笔记入口。代码变化、论文版本改变、旧笔记、离线读取和人工决定保留均单独复查。真实供应商生成质量和学习节省时间由用户后续实测填写。
