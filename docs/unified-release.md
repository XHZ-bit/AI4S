# PaperStride 1.0.0：升级、演示与交付说明

日期：2026-10-30。适用范围：Windows 本机单用户与受限评审交付。正式报告、PPT 和视频保留，由项目方另行处理；本说明不声称软件已提交比赛后台。

## 当前入口与知识边界

日常路径是“资料 → 统一知识图谱 → 原文核对 → 学习、比较或练习 → 保存成果”。主导航“知识图谱”和快捷搜索可查节点及空间归属，研究空间默认进入图谱工作台。账号资料库保存未归属空间的知识，各空间保存独立修订，原始资产可复用。

`kw_*` 保存活跃来源、节点、关系、证据和版本。旧项目接口与 `/api/graph/*` 通过兼容层读取统一知识；整数旧 ID 通过映射解析。Neo4j 作为可选历史/投影能力，不再决定主图谱读取或审核是否成功。旧研究方案、研究事实版本与冻结快照仍有历史含义，不将新讲解回写为已经审核的事实。

迁移保留审核等级、撤回/拒绝状态、ID 映射和进度；缺少可靠定位的历史内容明确保留缺失信息。迁移本身不调用模型。实际数据切换必须在备份、迁移回归及范围隔离验收完成后执行，不能用新建演示库代替实际数据迁移验收。

## 可移植演示

在项目根目录安装依赖并运行：

```powershell
.\scripts\setup-dependencies.ps1 -SkipParserModels
.\demo.ps1 -Synthetic -Action Prepare
.\demo.ps1 -Synthetic
```

默认目录 `.demo/synthetic-data` 与真实库 `backend/data` 独立。`demo-manifest.json` 中的 `paths` 给出图谱、学习、练习、比较入口；`unified_demo.node_ids` 保存明确节点 ID，便于浏览器验收。

演示包含 3 份原创教学 Markdown：共同前置知识、方案 A 线性残差、方案 B 有界残差。共同前置覆盖局部梯度、链式法则和高斯分布。节点与关系引用真实保存的文本块，公式和图 1 可定位；图 1 是按定义实际计算的原创曲线。

两方案在同一标量输入及 α 下比较定义、残差边界、导数；真实任务成功率、收敛与硬件成本明确为未知。预置比较是人工教学成果，不是模型评测或论文性能排名。原有 SyntheticProbe 合成研究事实、人工方案与快照继续保留，不重新编写为“真实论文”。

教学练习在浏览器 Python 中实际计算残差曲线、解析/数值导数表格和固定种子的高斯采样。修改 `alpha`、`mu`、`sigma` 后重新运行会改变结果。输出使用受限 `PAPERSTRIDE_VISUAL:` JSON 协议展示折线、表格、散点和柱状图；它不执行任意 HTML，也不自动将学习状态标为掌握。

资源使用当前资料图像和现有目录中的教程/视频入口。外站地址可访问、已经读取内容、可作为当前证据是不同状态。视频点击才加载；离线演示不依赖外站能播放。无匹配资源时显示站外搜索入口，不构造虚假视频 URL。

演示准备不联网，不调用语言模型或 OCR 模型；本地依赖与浏览器运行资源仍需首次安装。`--check` 仅校验不写入；识别到旧 schema 1 演示的正常准备只增加统一图谱，保留现有记录。未知标记、哈希错误及缺失文件会中止而不重置目录。新库采用 staging 完成后原子重命名，资产路径指向最终位置；Windows 临时文件锁仅作有界重试。

## 五条验收路径

| 路径 | 可核对结果 |
| --- | --- |
| 首页搜索 → 节点 → 关系解释 → 原文 → 返回 | 作用域、关系方向/依据和原文定位正确；返回保留位置 |
| 导入 → 分阶段分析 → 新增子图 → 修订 → 刷新 | 进度留在当前空间，修订持久化，另一空间不受影响 |
| 节点 → 前置路径 → 讲解/演示 → Python → 状态 | 前置来自已保存关系，计算输出可复算，状态由用户选择 |
| 两方法 → 表格/关系比较 → 依据 → 保存/再打开 | 条件与未知保留，比较引用可定位，成果可恢复 |
| 节点资源 → 图像/视频/代码 → 原站/预览 → 返回 | 按需加载，无自动播放，原图依据可定位，现场保留 |

## 升级与恢复

已有本机资料从旧版本原位升级时，先停止服务并完成备份，然后显式执行一次迁移：

```powershell
.\stop.ps1 -Mode Local
backend\.venv\Scripts\python.exe backend\scripts\data_archive.py backup --data-dir backend\data --output .local-backups\before-1.0.zip
backend\.venv\Scripts\python.exe backend\scripts\migrate_knowledge_workspace.py --data-dir backend\data
.\start.ps1 -Mode Local
```

默认处理本地根资料库及已注册账号的独立资料库；`--root-only` 仅处理根资料库。迁移可重复执行，按旧 ID 映射、导入版本和内容指纹去重，不调用模型。打开页面不会隐式迁移整库。原位升级不使用 `--relocate-from`；恢复到其他目录时才执行下面的资产重定位步骤。

升级前停止运行并保存可恢复的源码与资料备份。资料备份使用项目解释器运行 `backend/scripts/data_archive.py`；恢复目标必须是新的目录。启动恢复副本前必须运行 `migrate_knowledge_workspace.py --data-dir <恢复目标> --relocate-from <原数据目录>`，验证原件哈希并重定位 `kw_assets` 路径，然后核对数据库、原文、图谱与历史快照，再选择启动用的 `-DataDir`。已有备份不覆盖。本机已准备可由标准工具校验的 `standard-data-backup.zip`，具体路径与完整命令见[本地数据恢复](local-data-recovery.md)。

若迁移或解析中断，保留目录及诊断信息，基于进度记录重新运行；不要删除原始数据库或手动清空 `kw_*` 来“重新开始”。不将来源缺失改为已经验证，不为迁移重新请求模型生成知识。对具体运行目录的实际切换与冻结时间另记在验收报告中。
