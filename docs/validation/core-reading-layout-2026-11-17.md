# 核心工作页面空间巡检与改进

## 范围与取舍

继续上一轮深入学习阅读区改进，本轮检查原文阅读、节点练习、资料比较、学习路线、空间资料与记录、课题图谱、全局图谱和探索，以及独立课程、资料库论文阅读入口。优先桌面网页端，手机适配不在本轮范围。

| 页面 | 确认的问题 | 处理 |
| --- | --- | --- |
| PDF原文 | 资料、公式、关联知识、PDF工具和定位片段可以叠成多行 | 合成紧凑资料命令行；定位片段并入PDF工具行，余高由实际位置计算 |
| 文本与源码 | 内容随整页拉长，定位可能把整个页面滚走 | 章节查找放入导航，正文独立滚动，行号定位限定在正文内部 |
| 节点代码练习 | 外层抬头、页脚与标题仍占较多空间 | 共用紧凑外框，标题与返回合行，保留已有可调分栏与运行操作 |
| 比较 | 重复上下文，配置、关系说明先于比较结果；固定68vh高度可能越过屏幕底部 | 顶部保留一套返回和主操作，设置按需展开，比较表提前、按真实余高滚动，表头与首列固定 |
| 学习路线 | 已有路线也需要先越过规划表单与说明 | 已保存目标、继续操作和步骤优先，调整目标可展开，初次无路线仍直接显示规划表单 |
| 空间资料与记录 | 导入表单长期占据首屏，研究记录在资料列表末尾 | 有资料时收起导入，添加资料一键展开；资料与研究记录以首屏标签切换，内容不卸载 |
| 课题与全局图谱、探索 | 已有紧凑工具与视口画布，但外层仍重复预留底部与页脚 | 统一核心工作区外框；保留原画布与节点交互 |
| 独立课程、资料库论文阅读 | 通用页框及较大标题挤占内容 | 桌面压缩外框与阅读标题，课程、记录及原入口保留 |
| 全局资料库、首页、任务和设置 | 资料库已经按资料、导入和检索分区；其余是正常列表与表单 | 保留正常文档流，不强行做成固定高度阅读器 |

## 操作连续性

全部沿用已有导入、生成、运行和保存接口，没有加入新的自动模型请求。导入表单、研究记录、比较设置和路线目标在折叠时保持挂载。来源变化、操作失败与版本冲突继续显式展示。

原文保留PDF目录、页码、搜索、全屏、证据高亮及返回目的地。比较表从长页面改为独立滚动，验收同时检查选中比较项及其依据从原文返回后的恢复，避免视觉重排破坏核对过程。
