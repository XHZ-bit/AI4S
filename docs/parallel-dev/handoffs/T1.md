## 实现内容

### SQLite 业务结构

- 全部使用 `research_*` 新表，未修改或迁移旧论文、任务、学习记录、路线和案例表。
- 项目、论文关联、事实、决策和方案使用追加版本；快照不可变。
- 论文关联冻结当时的 `document_id` 与 `sha256:content_hash` 文档版本。
- 保存证据、字段证据、方法卡、实验设置、测量、审核转换审计和用户决策。
- 乐观并发冲突携带当前版本；写事务使用 `BEGIN IMMEDIATE`、参数绑定和显式提交/回滚。
- 相同论文、角色和备注在当前项目版本下幂等返回原关联，不重复递增项目版本。
- 事实新版本/状态变化、项目条件变化、决策取代、方案新版本和论文关联移除只标记依赖快照
  `needs_review`，不改写冻结内容。
- 保存快照与写入 `research_projection_outbox` 待同步记录在同一事务完成。
- 图投影失败记录 `failed/attempt_count/last_error`；已保存快照和用户决策不回滚，可重试。
- 新异步任务使用字符串 ID；相同活动任务参数幂等；终态不可静默重写；提供重启中断函数。

### API 与业务编排

- 实现冻结契约中 `/api/projects` 的项目、论文关联、事实状态、比较、决策、方案、快照、导出、
  任务查询/重试和图查询路由。
- 公共成功响应使用 `app.models.research` 模型；存储错误转换成统一错误详情。
- 抽取与方案生成在分发器未接入时先返回 501，不创建假任务或假成功结果。
- 实现供 `jobs.py` 调用的 `run_research_task`、`run_extraction_task`、
  `run_plan_generation_task` 和 `run_graph_projection`。
- T2/T5 使用延迟导入；缺失或不可用时任务明确失败。测试用替身验证抽取和图失败编排。
- 冻结的 `GET /api/projects/{project_id}/graph` 接收 `snapshot_id`、`node_ids`、`kinds`、`limit`，
  并通过 `kinds=dependency_path|method_context|impact_path` 暴露 T5 的依赖路径、方法上下文和影响路径查询。
- 查询前校验项目、快照归属与 SQLite 投影同步状态；查询后校验返回的项目和快照身份。`pending/running/failed`
  返回可重试的 `503 graph_unavailable`，T5 未接入返回 `501 not_implemented`，语义路径缺少锚点返回 422。
- T5 返回的节点、关系、解释路径和 `projection_status` 原样通过公共模型返回，没有固定节点列表或浏览器直连 Neo4j。
- 已接入并实际测试 T3 的 `compare_conditions`、`validate_decision`、`build_plan_draft`。
- JSON 与 Markdown 导出只读取冻结快照。
