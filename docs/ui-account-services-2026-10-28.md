## 账号使用

未登录用户可从顶部登录入口或「设置 → 账号与安全」进入登录、注册和找回密码。本机模式仍允许直接使用本机空间；多人模式必须先登录。

- 用户名为 3–64 位英文字母、数字、点、横线或下划线，以字母或数字开头；密码至少 12 个字符。注册、新密码表单要求重复确认。
- 注册可填写邮箱；收到验证邮件并完成验证后，才可使用邮箱登录或接收密码重置邮件。原账号可在账号与安全页验证当前密码后绑定邮箱。
- 忘记密码时选择邮箱找回，按邮件链接设置新密码。页面对存在和不存在的邮箱给出相同提示，避免透露注册状态。
- 没有配置邮件服务时，可在登录后生成并离线保存一次性恢复码。忘记密码后通过「恢复码找回」输入用户名、恢复码和新密码。
- 密码修改或重置后，旧会话全部退出。恢复码使用后失效；新恢复码会替换旧码。账号页支持查看当前有效会话并退出其他会话。

## 启用邮件服务

在部署使用的环境变量或 `.env` 中填写以下内容，然后重启后端。不要把 SMTP 密码提交到版本控制。

```dotenv
AUTH_PUBLIC_URL=https://research.example.com
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=your-smtp-account
SMTP_PASSWORD=your-smtp-password
SMTP_FROM_EMAIL=research@example.com
SMTP_SECURITY=starttls
SMTP_TIMEOUT_SECONDS=10
PASSWORD_RESET_MINUTES=30
```

`AUTH_PUBLIC_URL` 是用户实际访问的网站地址，用于生成邮件链接，不从浏览器请求中的 Host 拼接。生产环境使用 HTTPS；STARTTLS 通常配合 587 端口，隐式 TLS 使用 `SMTP_SECURITY=ssl` 和邮件商指定的端口。`plain` 仅允许连接回环地址上的本机测试邮件服务。

`OFFLINE_MODE=true` 同时关闭邮件外发；启用邮件时应关闭离线模式，并按需独立配置模型服务。

普通 Docker Compose 已通过 `env_file` 读取配置；多人 Compose 也显式转发以上变量。邮件未配置时，网页隐藏不可用的邮件操作并说明恢复码入口，不能仅凭代码已实现就认为真实邮件已可投递。

重置令牌仅在邮件链接的 URL 片段中传递，数据库只保存其哈希；验证与重置均为一次性操作，并受服务端限流保护。测试过程中使用独立账号数据库和本机 SMTP 接收器，不向真实收件人发信。

`REGISTRATION_ENABLED=false` 可关闭自主注册。公网多人部署继续使用安全 Cookie；仅在回环 HTTP 测试时按现有部署文档关闭 Secure 属性。
