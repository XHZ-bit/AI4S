## 目标与使用路径

PaperStride 服务初学者、跨学科学习者、研究者和教师。贯通带着问题导入资料、图谱找到起点、就地补基础、核对原文和实现、保存个人判断、下次直接继续。目标是减少重复解释背景、搬运资料、翻找出处和重建学习现场的操作。

## 工作台与个性化

- 首屏显示可编辑研究问题、相关知识图谱和一个下一步。用户可切换完整图谱。原文、节点或成果深链接直接到指定对象。
- 继承空间问题及使用方式。零基础探索首次使用重点理解，保存的讲解及人工选择优先。生成前可改目标、深度，打开页面只读已有内容。
- 建议依实际记录选择。先恢复暂停点，需要复习时按有效先修关系补基础，核查时就地打开依据。显示推荐原因，允许跳过或换路线。
- 原文保存、解析、知识分析分别反馈，已保存的原文立即可读。失败保留成功部分并在原处重试。

## 知识图谱与桌面交互

- 从已有有效节点和关系中组织问题、方法、公式、实验条件和发现。跨来源同名节点保留各自出处，候选关联需要核对。
- 节点单击打开独立侧栏，画布位置稳定。节点先给含义、主要操作、直接证据。前置知识沿用已有路径服务。
- 连线单击先显示起点、关系、终点、解释、来源和当前状态，修订与历史放第二层。自评理解与证据核查分别表达。
- 聚焦当前问题或学习路径，允许自由探索及列表。返回恢复节点、筛选、缩放、滚动和键盘焦点。
- 延用暖白、墨色、森林绿。避免标签重叠、连线穿节点、侧栏遮盖。宽公式、表格和代码在自身区域滚动。
- 桌面验证 1366×768、1440×900、1920×1080，覆盖两种主题、键盘和浏览器缩放。手机专项暂缓。

## 四批实施与接口

| 批次 | 改动 | 验收结果 |
| --- | --- | --- |
| 第一批 | 问题首屏、目标继承、初学者深度 | 同一问题只填写一次，从图谱进入匹配讲解 |
| 第二批 | 关系侧栏、问题聚焦、前置路径、精确返回 | 从知识进入出处再返回，选点不重排 |
| 第三批 | 对应版本传入练习、引用笔记、续学 | 保存预测、输入、输出、解释及证据，隔天一次恢复 |
| 第四批 | 方法机制和研究设计与发现模板，独立比较成果 | 逐格核对和更换依据，保存并导出快照 |

研究问题复用现有项目版本更新接口。任务暂停位置和未完动作按账号、空间保存在本设备。图谱与路径使用现有查询。练习生成接收已确认对应ID及修订版本，核对改变的来源。笔记保存证据快照、版本和位置。比较成果保存选择的单元格、个人判断及原始证据。旧资料和旧笔记继续兼容。

## 固定案例与验收

主案例为 Attention Is All You Need 固定版本 v7，比较材料为 Bahdanau 等人的 Neural Machine Translation by Jointly Learning to Align and Translate。跨学科使用 Roediger 与 Karpicke 的 Test-Enhanced Learning，检查问题、实验条件、发现、适用范围。案例通过正常导入建立，不硬编码论文ID。

Attention 教学题给定 Q·K=8、d_k=4，结果 8/sqrt(4)=4.0。这是 softmax 之前的缩放分数。自编实现显示教学性质，作者关联源码须固定完整提交和实际行段后再引用。

| 项目 | 目标 |
| --- | --- |
| 第一步 | 从已导入且解析完成的论文首屏到前置解释或目标原文至多3次主动操作 |
| 证据定位 | 选中节点后至多2次打开精确证据 |
| 连贯操作 | 同一任务重复填写问题0次，手工跨工具搬运资料0次 |
| 图谱质量 | 固定答案逐条统计正确、错误、证据不足、遗漏及方向问题 |
| 决定保留 | 错误候选驳回后重新生成仍保留决定 |
| 续学 | 首页一次操作恢复未决点；指出变动的来源一侧 |
| 性能 | 固定约500节点空间，已加载节点选择反馈P95目标200毫秒以内，记录设备和冷热口径 |
| 回归 | 旧笔记、来源改变、修订冲突、服务不可用、生产构建 |

与网页AI使用同一材料、题目和答案标准，允许其原生项目、文件、历史能力。由用户后续执行，分别记录操作与等待时间、重复说明和引用定位命中数。工程检查通过后才报告结果，学习成效和节省时间比例等待实测。
