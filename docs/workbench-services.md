# 课题工作空间与便捷服务

## 从一个课题开始

PaperStride 1.0 的研究空间默认进入统一知识图谱，主流程见[当前交付说明](unified-release.md)。本页继续说明资料导入、阅读辅导等兼容工具。学习偏好绑定真实研究空间 ID，进入“围绕本课题学习”或论文旁“继续辅导”时自动采用；个人全局关闭的功能优先。

在课题中点击“添加资料”，再拖入 PDF，保存后的论文会自动关联课题。关联失败时原文仍保留，可以在工作空间重新关联。也可使用“关联已有论文”。

## 添加资料

论文库支持粘贴 DOI、doi.org 链接、arXiv 编号或 arxiv.org 链接。通过固定的 Crossref/arXiv 官方服务获取书目信息，重复标识复用已有论文，不覆盖已有原文。DOI 元数据不保证提供全文，可继续上传 PDF。其他网站链接提示使用 PDF 上传，不会任意抓取内网或第三方 URL。

Crossref 接口依据：[官方 REST API 文档](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)。联网失败会保留输入并提供重试提示；导入元数据不调用付费大模型。

## 阅读与搜索

在 PDF 文字层选中一段内容，可解释术语、拆解公式、保存摘录或加入待解决问题。笔记携带论文、页码和选中文字，可返回原文；扫描件没有文字层时需要先完成 OCR。

Ctrl/Command + K 可搜索论文、课题、笔记、同步代码草稿、辅导和科研任务。结果直接进入对应记录。“个人设置 → 我的笔记”可查看跨设备保存的个人记录。

## 同步与冲突

阅读位置使用原有服务端保存。代码草稿、实验解释和笔记编辑草稿新增自动同步，显示保存状态；离线时保留浏览器暂存，恢复联网后重试。跨设备需要连接同一部署并登录同一账号，不能自动访问另一台电脑的 127.0.0.1 服务。

记录采用递增版本。另一设备写入后，旧版本保存返回冲突，不静默覆盖；用户可以比较服务端文本，选择服务端版本或保留本地内容再同步。浏览器暂存会在账户切换时清理。

## 整理与导出

课题工作空间可将已保存论文和研究记录整理为阅读报告、文献对比表、组会提纲、实验记录。编辑后可导出 Markdown 或保存到课题记录。缺失实验条件、结论和比较结果明确留待填写，不编造研究结果。课题 JSON 导出包含关联资料和记录。

个人设置中的“导出我的研究数据”导出书目、课题版本、笔记、辅导、练习和阅读位置等结构化数据；排除 API Key、身份数据库、密码和会话令牌，不打包 PDF 或头像。需要原始文件时通过论文原文入口保存。

## 账号恢复与会话

登录后在“账号与安全”确认当前密码，生成一次性恢复码并离线保存。新码替代旧码。忘记密码时在登录表单附近展开“使用恢复码”，重设密码会销毁恢复码并撤销全部登录会话。恢复失败实行持久化尝试次数限制。

没有预先保存恢复码时，仍需维护者通过已有账户管理工具处理；此版本不发送邮件、不依赖未配置的邮件服务。

会话列表显示登录和到期时间，标识当前会话；“退出其他会话”保留当前会话。普通用户只能管理自己的会话。

## 失败恢复

后台任务页继续支持按当前任务重试、取消，新增按认证、网络和解析错误分类的操作建议。原文先保存，解析失败可重试解析，不要求删除论文重传。笔记保存失败保留草稿；所有新接口使用当前账号的独立工作空间。

## 验收

后端覆盖：跨账号隔离、版本冲突、课题关联、DOI 去重与非法 URL、数据导出、课题偏好传入导师、恢复码一次性与尝试限制、会话撤销。

浏览器覆盖：新账号注册、课题笔记与报告、全局搜索、独立浏览器上下文之间恢复草稿和冲突处理、恢复码生成、退出其他会话、实际文件下载、PDF 选文及页码、手机深浅色布局。测试使用专用验收账号，不修改原用户资料。
