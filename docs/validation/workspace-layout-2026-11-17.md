# 课题工作台：紧凑工具区与可调整节点详情

本轮回应实际页面反馈：顶部多个信息量很小的区域纵向堆叠，而节点正文被限制在约330px的固定栏内。修改限定桌面课题图谱工作台，不增加手机适配工作，不改动用户的知识、笔记和资料内容。

## 使用方式

- 顶部课题标题和空间操作缩为紧凑行；当前问题与图谱范围切换同排。没有问题时直接显示“写下问题”，不再保留大段占位标题和解释。长问题可展开全文，编辑与保存入口保留。
- 搜索、来源范围、筛选、新增节点、导入和图谱呈现方式集中在工具区；关联位置与学习路径入口共用下一行，路径内容按需展开。
- 点击节点后，详情默认约占工作区40%，通常为420–560px；把鼠标放到图谱与详情中间的分隔线，向左拖可加宽详情，向右拖可加宽图谱。
- 分隔线支持键盘：左/右方向键调整16px，Shift加速至64px，Home/End到两端，Enter或双击恢复默认宽度。详情栏也有“恢复默认宽度”按钮。
- 点击“展开节点详情”可使用工作区全宽阅读；“还原分栏”返回图谱对照。展开过程保留当前节点、标签页、未保存文字和图谱组件。
- 详情正文在栏内滚动，标题、标签页和底部动作保持可用；原文摘录跟随正文滚动，去掉摘录的额外纵向滚动框。宽公式和代码仍在自身区域横向滚动。

## 布局与存储边界

分栏按实际容器宽度计算，右侧最小320px，最大取880px与“容器宽度减320px图谱及12px分隔线”的较小值。窄到不足以双栏时显示详情阅读，恢复分栏操作明确禁用，放宽窗口后恢复可用。

高度按图谱区域在视口内的实际位置计算，分别为底部图谱控件和详情正文留出空间。图谱较窄时预留多行控件的高度。窗口尺寸、顶部展开内容变化时重新计算，不因为普通节点选择重新适配或排列图谱。

宽度偏好保存于本账号、本课题、本浏览器的localStorage，键名 `paperstride:{account}:graph-detail-width:{project}`。窗口缩小时仅临时限制显示宽度，不覆盖原偏好；恢复窗口后可以回到原宽度。账号切换继续遵守现有会话清理规则，不改变登录和缓存策略。此偏好不跨设备同步。

实现集中在 `GraphSplitLayout.tsx` 和独立CSS，沿用现有课题数据、编辑、阅读、笔记与图谱接口。没有新增后端服务或模型请求。
