# 课题关系网络与节点资料、笔记

本轮根据用户实际截图，在研究课题内提供与全局探索相同的点线关系网络，并让节点承载个人说明、资料和文字记录。桌面网页优先，沿用现有课题、知识与账号存储。

## 使用入口

进入左侧任一研究课题，在图谱工具栏切换“关系网络”。“结构图”和“内容列表”继续保留，呈现偏好按账号及课题保存。切换完整图谱可浏览当前课题已加载的有效节点；围绕问题、来源、路径或路线的筛选继续有效。

- 选中节点时，节点自身提亮并适度放大，取消全局和课题网络的选中描边圆环。选中标签优先可读，其他节点保持原类型颜色。
- 点节点打开现有详情侧栏，使用“编辑节点”修改名称、说明及已有状态或公式字段。
- 点击“新增节点”可以直接填写名称、类型和说明，空课题也能开始整理想法。手工节点明确记录为用户内容，有自己的Markdown原件，不冒充论文事实。
- 在“原文与资料”中打开“节点资料”，可以关联本课题已有资料，或上传文件并直接关联当前节点。资料备注可以编辑，移除关联保留课题原件。
- 在“笔记与提问”中先写并保存笔记。重新点击节点时，“知识与学习”首屏显示保存的文字摘要，可以展开全文或继续编辑。

## 数据边界与持久化

课题关系网络只消费现有项目图谱接口的数据，不请求全局图谱。渲染器再次校验项目归属，避免其他课题记录混入。节点、证据、编辑和笔记仍使用各自课题的已有接口；全局探索继续提供跨资料浏览。

网络布局与镜头按账号、课题、来源或路线分别保存到本机浏览器。普通画布点选保持镜头，底部定位控件才主动定位；节点拖动、编辑刷新和重新打开可恢复布局。不同设备的网络位置不在本版同步范围。

节点资料保存关联ID、课题、节点、来源、备注、来源版本快照、操作者和修订历史。来源移除或变化后保留旧备注和快照；并发修改要求预期修订号。服务端拒绝跨课题与跨账号绑定，移除关联不删除来源原件。

上传附件使用原有文件存储，但不自动排入模型分析。2MB以内支持的文本、Markdown和代码通过原生解析立即可读，不执行上传代码。PDF可以使用原件阅读器；复杂文档和较大文本保留原件，深度解析沿用资料入口。上传后绑定失败会返回已保存来源信息，页面可改从本课题已有资料继续关联。

个人文字复用节点笔记存储，不另建一套正文。来源引用、原有人工修订、旧笔记和AI回答摘录的身份保持不变。网络提示文本进行HTML转义，用户输入作为文字显示。

## 新增接口

根路径为 `/api/projects/{pid}/knowledge`。

| 操作 | 接口 |
| --- | --- |
| 新增手工节点 | POST `/nodes` |
| 读取或关联资料 | GET/POST `/nodes/{nid}/materials` |
| 上传并关联 | POST `/nodes/{nid}/materials/upload` |
| 修改备注或移除关联 | PATCH `/nodes/{nid}/materials/{id}` |
| 关联修订历史 | GET `/nodes/{nid}/materials/{id}/history` |

普通节点编辑、笔记、图谱和阅读继续使用既有接口。
