# 新资料覆盖、基础学习与跨论文核对

本轮继续建设桌面网页端，补齐新资料进入后的覆盖检查、基础内容、针对具体回答的指导及跨论文概念核对。接续 [上一轮桌面建设](desktop-workspace-2026-11-16.md)。

## 使用入口与实际行为

| 入口 | 新增行为 |
| --- | --- |
| 资料与记录，每份资料下方 | 展开“检查内容覆盖与缺项”，查看问题、方法、实验、发现和局限的有效节点及出处。缺项可以主动补充分析，也可写理由标记原文未报告或不适用。 |
| 原文关联公式 | 直接学习这条公式，或展开符号与条件。读取已提取的符号含义、维度、单位和条件，能够返回实际原文位置。 |
| 深入学习与教学补充节点 | 新增点积、缩放注意力、softmax、概率、研究设计和样本六类内容，模型关闭时仍可读已编写的基础章节和运行交互演示。 |
| 深入学习的“用一个问题检验理解” | 自愿回答固定教学题并保存个人理由。根据具体误解给下一步建议，支持跳过、重开历史及反馈建议不适合。 |
| 研究空间首屏 | 读取当前有效的教学回答记录，针对具体回答推荐补充知识，允许更换起点。 |
| 图谱节点及深入学习工具区 | 展开跨论文概念核对，全空间寻找候选或手工选择，逐侧核对定义、条件、原文、版本，保存四种个人判断。 |

基础内容属于自编教学补充，以 SUPPLEMENTS 与原知识关联，不借用论文引用。普通心理学“注意力”不会直接触发缩放点积教学。原文未给出的维度、单位和定义保持待核对。可识别的残缺等式会提示回原文，人工修订文字保留。

## 关键约束与兼容

覆盖检查读取当前有效且有出处的语义节点。章节结构和教学节点不计入论文研究内容覆盖。节点数量及覆盖状态用于发现缺项，科学正确性仍需核查。补充分析由用户主动触发，每次仅将所选类型的有限片段发给模型，最多一次请求。非法引用不会落为有效知识，生成期间来源、解析、人工决定或完整分析状态变化时保留已有结果并要求复核。

教学检查保存题面、所选回答、本人理由、反馈、操作者、知识与证据指纹。它只判断题目给定条件下的回答，学习状态继续由用户自评。来源或题面变化后保留旧回答，失效记录退出当前推荐。反馈建议不适合后，推荐会跳过相应记录。

概念候选使用空间内本地词项、双语术语和定义上下文匹配。用户可保存“可对照”“条件有差异”“暂无法确定”“驳回”。前两种以用户判断关系进入图谱，来源或任一侧节点、同ID证据变化后退出当前图谱与讲解复用，历史仍可重开。确认需要两侧节点版本、来源版本及证据内容指纹，防止用户看到的摘录被静默替换。

## 接口

- GET/PATCH `/api/projects/{pid}/sources/{sid}/coverage` 读取覆盖和保存人工判断，POST `/coverage/supplement` 按需补充。
- GET `/api/projects/{pid}/knowledge/nodes/{nid}/checks` 读取教学题与历史，POST `/{check_id}` 保存回答，POST `/{attempt_id}/dismiss` 保存个人反馈。
- GET `/api/projects/{pid}/knowledge/checks/recommendation` 读取由现有回答形成的建议，不调用模型。
- GET/POST `/api/projects/{pid}/knowledge/nodes/{nid}/concept-correspondences` 获取候选与保存判断，PATCH `/{id}` 修订已有判断。

知识、笔记、原文及已有实践记录沿用现有接口。新记录按账号和研究空间隔离。
